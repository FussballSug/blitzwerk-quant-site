# Blitzwerk Kapital public site

Public, account-free Streamlit information site for Blitzwerk Kapital, a US AI quantitative trading technology company. It describes the research mission, process, AI responsibility roles, and paper-first operating principles.

This repository is the sanitized deployment mirror for the private `FussballSug/blitzwerk-quant` engineering repository. Streamlit reads this public mirror so it never needs access to the private trading codebase. Website changes are developed and reviewed in the private repository, then the approved public-only files are copied here for deployment.

This repository contains no broker integration, credentials, account identifiers, balances, positions, orders, fills, P&L, private incidents, approvals, or trading controls.

Run with `streamlit run streamlit_app.py`.
